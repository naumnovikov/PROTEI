# PROTEI

## Краткое описание (цель)
**PROTEI** — консольный симулятор работы мобильной сети 4G на C++, созданный в рамках тестового задания для поступления на стажировку в НТЦ "ПРОТЕЙ".

## Основные возможности
- Загрузка и валидация конфигурации из JSON-файла для SIMTEL и для UE
- Регистрация UE в сети(запрос уровня сигнала, выбор лучшей BS, получение временного идентификатора TMSI)
- Хранение данных абонентов в SQLite-БД: HLR, VLR, EIR
- Обработка SMS: отправка через SMSC с присвоением SMS‑ID, хранение сообщений до доставки или истечения TTL, возврат статуса отправителю
- Поддержка Handover: при команде MOVE BS проверяет необходимость переключения на другую станцию; UE получает команду перехода с новым IP/портом и переподключается
- Многопоточная обработка клиентов на сервере
- Возможность одновременной работы нескольких UE, обменивающихся SMS

## Перед сборкой
**NB**: В конфигурации по умолчанию указывается дефолтный рабочий IP для запуска программы клиента и сервера на одном и том же PC. В случае, если есть необходимость тестировать программы на разных PC, то нужно узнать локальный IP этого PC:
```bash
hostname -I
```

### Конфигурация, cборка и запуск серверного приложения**SIMTEL**
NB: При сборке SIMTEL, а также tests может выходить предупреждение. Это нормально, оно связано со старой версией fmt в spdlog, а не какой-либо ошибкой в коде.
```bash
git clone -b task_05 https://github.com/naumnovikov/PROTEI.git
cd PROTEI
mkdir build && cd build
cmake .. -DBUILD_SIMTEL=ON
make
cd SIMTEL
./SIMTEL
```
### Конфигурация, cборка и запуск клиентского приложения **UE**
```bash
git clone -b task_05 https://github.com/naumnovikov/PROTEI.git
cd PROTEI
mkdir build && cd build
cmake .. -DBUILD_UE=ON
make

./UE
```

## Использование UE
После запуска и ввода имени конфига:

- ACTIVE TRUE – выполнить регистрацию в сети (Attach), получить TMSI

- ACTIVE FALSE – отключиться от сети

- MOVE X Y Z – изменить координаты (например, MOVE 10 20 30). Если новая позиция оказывается в зоне действия другой BS, автоматически выполняется Handover

- SMS <MSISDN> <текст> – отправить SMS указанному абоненту (например, SMS 89991112233 Hello). После отправки выводится статус «SMS sent»

- EXIT – завершить работу

Входящие SMS и уведомления о доставке выводятся в консоль асинхронно.
