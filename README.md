# PROTEI

## Краткое описание (цель)
**PROTEI** — консольное приложение на C++, созданное в рамках обучения в IT-школе НТЦ ПРОТЕЙ.

## Основные возможности
- Загрузка и валидация конфигурации из JSON-файла для сервера и для клиента
- Клиент-серверное взаимодействие (клиент отправляет координаты, сервер отвечает расстоянием до него)
- Многопоточная работа сервера
- Таймаут при работе с каждым из клиентов (120 с), а также общий таймаут сервера при остуствии взаимодействия (240 с)
- Подробное логирование с указанием времени, файла и строки с разделением на разные уровни
- Юнит-тесты для основных компонентов

## Перед сборкой
**NB**: Перед сборкой важно убедиться в том, какой локальный IP на вашем ПК. Для этого нужно сделать:
```bash
hostname -I
```
Далее необходимо указать в используемых конфигурационных файлах соответствующий IP. Например, для конфигурации app, можно изменить в файле config.json поле IP. Порты важно указывать в соответствии с IANA Registered Ports (1024 – 49151). Для конфигурации сервера нужно провернуть соответствующую манипуляцию с файлом serverconfig.json.
**И только теперь можно заняться сборкой**
### Конфигурация, cборка и запуск **server**
NB: При сборке server, а также tests может выходить предупреждение. Это нормально, оно связано со старой версией fmt в spdlog, а не какой-либо ошибкой в коде.
```bash
git clone -b task_04 https://github.com/naumnovikov/PROTEI.git
cd PROTEI
mkdir build && cd build
cmake .. -DBUILD_SERVER=ON
cmake --build .
cd CORE
./server
```
### Конфигурация, cборка и запуск клиентского приложения **app**
```bash
git clone -b task_04 https://github.com/naumnovikov/PROTEI.git
cd PROTEI
mkdir build && cd build
cmake .. -DBUILD_APP=ON
cmake --build .
cd APP
./app
```
### Конфигурация, cборка и запуск **tests**
```bash
git clone -b task_04 https://github.com/naumnovikov/PROTEI.git
cd PROTEI
mkdir build && cd build
cmake .. -DBUILD_TESTS=ON
cmake --build .
cd TESTS
./tests
```

## Чего удалось достичь 
**Improvements**:
- разделил CMakeLists на разные части, так как есть 3 вида target (каждый CMakeLists для своего). Разделил main на 3 файла под каждый target(app, server, tests)
- указал Latest Release версии для всех подключаемых в конфигурацию репозиториев: json, spdlog, googletest
- заменил std::vector<char> на std::string для IMEI и IMSI ради SSO
- разделил бизнес-логику работы с сокетом и базовую некоторую работу с сокетом
- добавил RAII для сокетов (sock.h)
- для конфигурации App теперь не обязательно в JSON-конфиге иметь поля nodes и config
**Fixes**:
- исправил логическую ошибку, связанную с лишним портом клиента
- исправил логическую ошибку, связанную с неправильным порядком выделения памяти на вектор в getDistance() и getCoordinates() в классе SocketBusinessWorker
