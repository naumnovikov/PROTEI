# PROTEI

## Краткое описание (цель)
**PROTEI** — консольное приложение на C++, созданное в рамках обучения в IT-школе НТЦ ПРОТЕЙ.

## Основные возможности
- Загрузка и валидация конфигурации из JSON-файла для сервера и для клиента
- Клиент-серверное взаимодействие (клиент отправляет координаты, сервер отвечает расстоянием до него)
- Многопоточная работа сервера
- Таймаут при работе с каждым из клиентов (120 с), а также общий таймаут сервера при остуствии взаимодействия (240 с)
- Подробное логирование с указанием времени, файла и строки с разделением на разные уровни
- Юнит-тесты для основных компонентов

## Процесс сборки
**NB**: Перед сборкой важно убедиться в том, какой локальный IP на вашем ПК. Для этого нужно сделать:
```bash
hostname -I
```
Далее необходимо указать в используемых конфигурационных файлах соответствующий IP. Например, для конфигурации приложения, можно изменить в файле config.json поле IP. Порты важно указывать в соответствии с IANA Registered Ports (1024 – 49151). Для конфигурации сервера нужно провернуть соответствующую манипуляцию с файлом serverconfig.json.
**И только теперь можно заняться сборкой**
### Основная программа
```bash
git clone -b task_04 https://github.com/naumnovikov/PROTEI.git
cd PROTEI
mkdir build && cd build
cmake .. -DCMAKE_BUILD_TYPE=Release
```
### Сборка и запуск основного приложения App
```bash
cmake --build .
./app
```
### Сборка и запуск основного приложения Server
NB: При сборке сервера, а также тестов может выходить предупреждение. Это нормально, оно связано со старой версией fmt в spdlog, а не какой-либо ошибкой в коде.
```bash
cmake --build . --target server
 ./server
```
### Сборка и запуск тестов
```bash
cmake -DBUILD_TESTS=ON ..
cmake --build .
./TESTS/protei_tests
```
